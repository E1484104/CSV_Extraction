项目命令行参数速查
====================

通用说明
--------
- 六个入口：main.py、vevo_stitcher.py、ultrasound_normalizer.py、wearable_normalizer.py、csv_interval_matcher.py、paired_window_search.py。
- --root 用于指定一次实验的根目录；只有没有手动输入 --input 或 --output 时才会生效。
- 如果同时输入 --root 和 --input/--output，显式输入的 --input/--output 优先。

默认实验目录结构：
ROOT_PATH/
  Raw_Images/
    series_1/
    series_2/
  Stitched_Images/
  raw_data/
  norm_data/


1. vevo_stitcher.py：图片拼接
-----------------------------
用途：把 Raw_Images/series_* 中的连续小图拼接成长波形图。

常用命令：
python vevo_stitcher.py --root "../Tester1"

默认路径：
- 输入：ROOT_PATH/Raw_Images
- 输出：ROOT_PATH/Stitched_Images

路径参数：
- --root：实验根目录。
- --input：输入图片文件、图片文件夹、多个 series 文件夹，或包含多个 series 子文件夹的父目录。
- --output：输出 PNG 文件路径，或批量拼接时的输出文件夹。

ROI 与曲线识别：
- --roi：手动指定裁剪区域，格式为 x,y,width,height。
- --auto-roi：强制使用自动 ROI，而不是内置 Vevo 全屏 ROI。
- --feature：选择用于匹配的曲线颜色，可选 auto、blue、green；默认 auto。
- --tolerance：blue/green 曲线识别的 RGB 颜色距离容差，默认 150；越大越不容易因色差断线，也越容易包含同色噪声。
- --keep-static：保留原图中的非曲线静态内容。
- --draw-axis：在输出图中画一条连续横轴。
- --background：清理静态内容后的背景灰度值，默认 0。

图片顺序与匹配：
- --order：输入顺序，可选 auto、given、reverse；默认 auto。
- --min-shift：搜索的最小水平位移，默认 20。
- --max-shift：搜索的最大水平位移；默认自动取较窄图片宽度减去 min-overlap。
- --min-overlap：匹配时要求的最小重叠宽度，默认 50。
- --min-score：接受拼接对的最低匹配分数，默认 0.30。
- --blend-width：拼接处做最大值融合的宽度，默认 8。

seam 检查与跳帧恢复：
- --seam-check：接缝检查模式，可选 auto、on、off；默认 auto。
- --seam-window：接缝左右各搜索多少列，默认 16。
- --max-seam-gap：接缝允许的最大水平断点距离，默认 8。
- --max-seam-y-gap：接缝允许的最大垂直断点距离，默认 20。
- --seam-score-bypass：auto seam 模式下，高于该分数可绕过不确定接缝检查，默认 0.95。
- --skip-recovery-mode：跳帧后的恢复方式，可选 score、expected-shift、off；默认 score。
- --skip-recovery-tolerance：expected-shift 模式下允许的 shift 误差，默认 25。
- --bridge-seams：在接缝处画短连接线；默认关闭。
- --bridge-width：bridge 线宽，默认 3。

自动 ROI 辅助参数：
- --x-padding：自动 ROI 左右扩展像素，默认 0。
- --y-padding：自动 ROI 上下扩展像素，默认 70。
- --y-padding-top：自动 ROI 顶部扩展像素，覆盖 y-padding 的顶部值。
- --y-padding-bottom：自动 ROI 底部扩展像素，覆盖 y-padding 的底部值。
- --static-row-occupancy：超过该占比的行视为静态横线并忽略，默认 0.35。


2. main.py：图片提取 CSV
------------------------
用途：从拼接后的图片提取曲线 CSV。

常用命令：
python main.py --root "../Tester1" --no-plot

默认路径：
- 输入：ROOT_PATH/Stitched_Images
- 输出：ROOT_PATH/raw_data

路径与绘图：
- --root：实验根目录。
- --input：输入图片或图片文件夹。
- --output：输出 CSV 文件路径，或批量处理时的输出文件夹。
- --plot-output：保存绘图 PNG 的路径或文件夹；设置后会自动保存图。
- --save-plot：自动保存图，同时仍显示 Matplotlib 窗口。
- --no-plot：不显示也不保存图，只生成 CSV。
- --debug-image：输出调试图，显示 ROI、选中曲线和检测点。

图片曲线识别：
- --target-color：手动指定目标曲线颜色，格式 #RRGGBB 或 R,G,B。
- --tolerance：颜色距离容差，越大越容易包含抗锯齿边缘，也更容易包含噪声；默认 55。
- --roi：手动指定图片裁剪区域，格式 x,y,width,height；也支持 0-1 的归一化比例。
- --sample-step：每隔多少水平像素输出一个点，默认 1。
- --smooth-window：输出 y 值的中值平滑窗口，1 表示不平滑；默认 1。
- --min-area：候选连通区域的最小面积，默认 30。
- --min-span-ratio：候选区域相对 ROI 宽度的最小横向跨度偏好，默认 0.15。
- --min-neighbors：去除邻居数少于该值的孤立彩色像素，默认 1。
- --allow-flat：允许近似水平的组件被自动选中。
- --min-brightness：自动选色时的最低亮度，默认 45。
- --min-saturation：自动选色时的最低饱和度，默认 35。
- --auto-candidates：自动选色时尝试的候选颜色数量，默认 8。

真实坐标标定：
- --x-min：真实 x 轴最小值。
- --x-max：真实 x 轴最大值。
- --y-min：真实 y 轴最小值。
- --y-max：真实 y 轴最大值。

3. wearable_normalizer.py：Wearable BPI CSV 时间轴处理与绘图
----------------------------------------------------------
用途：读取 Wearable CSV，默认只生成新增 time_s 的处理后 CSV，
并用 Matplotlib 打开窗口查看 BPI 曲线。BPI 归一化需要显式开启。

常用命令：
python wearable_normalizer.py --input "../20260805/Test2/Wearable_2.csv"

默认路径：
- 输入：ROOT_PATH
- 输出：单个 CSV 时默认写到原文件旁边；文件夹输入时默认写到 INPUT/BPI_Processed

路径与绘图：
- --root：实验根目录；只有没有手动输入 --input 时才会作为默认输入。
- --input：输入 Wearable CSV 文件或包含 CSV 的文件夹。
- --output：输出 CSV 文件路径，或批量处理时的输出文件夹。
- --plot-output：保存绘图 PNG 的路径或文件夹；设置后会自动保存图。
- --save-plot：自动保存图，同时仍显示 Matplotlib 窗口。
- --no-plot：不显示也不保存图，只生成处理后 CSV。
- --timestamp-column：指定 timestamp 列名；默认自动识别 Timestamp。
- --bpi-column：指定 BPI 原始数据列名；默认自动识别 BPI。
- --normalize-bpi：额外生成 bpi_normalized，使用 BPI 的 min-max 归一化；默认关闭。
- --no-normalize-bpi：只新增 time_s，保留原始 BPI；这是默认行为。
- --denoise：开启旧的底噪抽样、删点和除底噪步骤；需要 --normalize-bpi；默认关闭。
- --noise-sample-count：只在 --normalize-bpi --denoise 时使用；在 min-max 归一化后随机抽取多少个有效点估计底噪，默认 2000。
- --noise-seed：底噪随机抽样种子，默认 0；固定 seed 可保证重复运行结果一致。
- --no-denoise：关闭归一化后的底噪抽样、删点和除底噪步骤；这是默认行为。
- --bpi-smooth-window-points：居中移动平均窗口点数；默认 1，即关闭 smoothing；必须为奇数。不使用 --normalize-bpi 时会对原始 BPI 平滑并新增 bpi_smoothed；使用 --normalize-bpi 时会对 bpi_normalized 平滑。
- --bottom-envelop：可选；需要 --normalize-bpi；在 Wearable 归一化和平滑之后估计下包络线，并让每个 bpi_normalized 点减去对应下包络线值，实现底部归零。

处理后的 CSV 会保留原列，并新增：
- time_s：每个 Timestamp 减去第一个 Timestamp。
- 默认不新增 bpi_normalized，也不改变 BPI 数值。
- 使用 --bpi-smooth-window-points N 且不使用 --normalize-bpi 时，会新增 bpi_smoothed：对原始 BPI 做 N 点居中移动平均，原始 BPI 列仍保留。
- 使用 --normalize-bpi 时，才新增 bpi_normalized：BPI 原始数据按 min-max 归一化；默认不做 smoothing，也不做随机底噪抽样、删点和除底噪。如果同时使用 --bpi-smooth-window-points N，会对归一化后的 bpi_normalized 做 N 点居中移动平均。如果使用 --denoise，会按旧流程随机抽取 2000 个归一化点取平均作为底噪，删除这些抽样点，剩余点除以底噪值，因此结果可能大于 1。如果使用 --bottom-envelop，会在上述处理之后减去下包络线，让曲线底部归零。

默认只打开 Matplotlib 窗口，不会在命令行询问是否保存图片。设置
--plot-output 或 --save-plot 时才会自动保存图片。


4. ultrasound_normalizer.py：CSV 统一归一化
-----------------------------------------
用途：读取 raw_data 中的 CSV，生成 norm_data 中的归一化 CSV。

常用命令：
python ultrasound_normalizer.py --root "../Tester1"

默认路径：
- 输入：ROOT_PATH/raw_data
- 输出：ROOT_PATH/norm_data

路径与文件选择：
- --root：实验根目录。
- --input：输入单个 CSV 或 CSV 文件夹。
- --output：输出单个 CSV 路径，或输出文件夹。
- --pattern：文件夹模式下匹配的 CSV 文件名模式，默认 *.csv。
- --recursive：递归搜索子文件夹，并在输出中保留相对路径。

归一化设置：
- --x-column：指定用于横轴的列；默认优先 x_px，其次 x_value。
- --y-column：指定用于纵轴的列；默认优先 y_px，其次 y_value。
- --duration-s：把每个 CSV 自己的横轴范围映射到 0..duration_s，默认 29.8 秒。
- --no-invert-y：不反转 y 轴；默认会把图像像素 y 轴转换成正常图表方向。


5. csv_interval_matcher.py：短 CSV 与长 CSV 波形区间匹配
--------------------------------------------------------
用途：给定一个短 CSV 和一个长 CSV，将短 CSV 的相对时间轴沿长 CSV 滑动，
逐个候选窗口评分，输出最相似的起始时间。

常用命令：
python csv_interval_matcher.py --root "../20260805/Test22"

python csv_interval_matcher.py --short "../20260805/Test2/Norm_Data/Test2-1.csv" --long "../20260805/Test2/Wearable_2_bpi_processed.csv"

已知多个短 CSV 按文件名排序且互不重叠时：
python csv_interval_matcher.py --short-dir "../20260805/Test2/Norm_Data" --long "../20260805/Test2/Wearable_2_bpi_processed.csv"

比较所有指标：
python csv_interval_matcher.py --short-dir "../20260805/Test2/Norm_Data" --long "../20260805/Test2/Wearable_2_bpi_processed.csv" --metric all --start-step-rows 10

显示完整 long，并把匹配后的 short 同时对齐到 long 时间轴：
python csv_interval_matcher.py --short "short.csv" --long "long.csv" --top 1

只有明确需要保存时才传 --plot-output：
python csv_interval_matcher.py --short "short.csv" --long "long.csv" --top 1 --plot-output "matched_overlay.png"

默认自动识别：
- 输入路径：未传 --short/--short-dir 时使用 ROOT_PATH/Norm_Data；未传 --long/--long-dir 时使用 ROOT_PATH/BPI_Processed 中唯一的 CSV。
- 时间列：time_s、x_norm、x_value、x_px、Timestamp。
- 数值列：bpi_normalized、bpi_smoothed、y_norm、y_value、y_px、BPI。

匹配与评分：
- 单个 --short 输入时，默认按长 CSV 的每一个时间点作为候选起点逐点滑动。
- --short-dir 输入时，默认按短 CSV 文件名字典序选择一组有序、互不重叠的区间。
- 对每个短 CSV 时间点，默认取长 CSV 中最接近的时间点。
- 对比图中，底部 x 轴是完整 long 时间；short 通过 long_time = match_start + (short_time - short_start) 映射到同一条时间轴。
- 对比图窗口上方是完整 long 叠加图，下方最多 4 张匹配窗口分块细节图；下方细节图会分别按局部可见窗口缩放 long/short 的 y 轴范围。
- 对比图使用双 y 轴：左侧是完整 long 数值列，右侧是所有 short 数值列，匹配窗口会用淡色背景标出；short 线半透明显示，方便看清下方 long 线。
- 默认 metric=pearson；fusion 仍可手动选择，基于 Test11/Test22 模式调参，融合普通 Pearson、平滑导数相关、平滑 Pearson 和少量形态特征相关。
- score 越高表示波形越相像；rmse_z、mae_abs、rmse_abs 越低表示误差越小。

常用参数：
- --root：实验根目录；用于缺省 short 和 long 路径。
- --short：输入单个短 CSV。
- --short-dir：输入短 CSV 文件夹，按文件名字典序处理。
- --short-pattern：short-dir 下匹配的 CSV 文件名模式，默认 *.csv。
- --long：输入单个长 CSV。
- --long-dir：输入长 CSV 所在文件夹，默认 ROOT_PATH/BPI_Processed；目录中必须只有一个匹配的 CSV，或用 --long-pattern 缩小范围。
- --long-pattern：long-dir 下匹配的 CSV 文件名模式，默认 *.csv。
- --short-x-column / --short-y-column：指定短 CSV 的时间列和数值列。
- --long-x-column / --long-y-column：指定长 CSV 的时间列和数值列。
- --metric：选择 fusion、fusion_derivative、pearson、spearman、rmse_z、mae_z、rmse_abs、mae_abs、bland_altman、bland_altman_abs、bias_abs、derivative、smooth_pearson、smooth_derivative、sign_agreement、feature_corr，或 all。
- --top：输出前几个匹配结果，默认 5。
- --min-start-separation-s：输出结果之间的最小起始时间间隔；用于避免 top 5 全部挤在同一段。
- --independent：使用 short-dir 时不做有序非重叠全局匹配，而是每个短 CSV 独立输出 top 匹配。
- --ordered-gap-s：有序非重叠匹配时，区间之间额外要求的间隔。
- --sample-method：nearest 或 linear；默认 nearest。
- --resample-points：每个候选窗口重采样为多少点后评分；默认 3000。
- --smooth-window-points：平滑指标使用的移动平均窗口点数；默认 15。
- --start-step-rows：每隔多少个长 CSV 点滑动一次；默认 1。
- --start-step-s：固定时间步长滑动；设置后覆盖 start-step-rows。
- --output：把 top 匹配表保存为 CSV。
- --plot-output：保存匹配对比图；一个 metric 可填 PNG 路径，多个 metric 必须填文件夹。
- --show-plot：直接打开 Matplotlib 对比图窗口；这是默认行为，除非使用 --no-plot。
- --no-plot：不打开 Matplotlib 对比图窗口；如果同时传了 --plot-output，仍会保存 PNG。

如果长 CSV 的 timestamp 丢失小数精度，可以用行号和采样率重建时间轴：
python csv_interval_matcher.py --short "short.csv" --long "long.csv" --long-x-column row_index --long-sample-rate 250


6. paired_window_search.py：paired CSV 统一窗口 Pearson 搜索
-----------------------------------------------------------
用途：读取 csv_interval_matcher.py 每次运行后生成的 matched_paired_points*.csv，
在所有 paired CSV 中使用相同窗口长度，寻找各 CSV 内 Pearson 最高的时间窗口，
并按所有 CSV 的平均 Pearson 输出 top 5，且 top 5 的窗口长度互不相同。

常用命令：
python paired_window_search.py "../20260814/Test6"

如果 paired CSV 集中在单独文件夹：
python paired_window_search.py "paired_csv_folder"

默认设置：
- --pattern：匹配 matched_paired_points*.csv。
- --expected-points：每个 CSV 必须有 3000 个有效 paired 点；如果不是 3000 点，用 --expected-points 0 关闭检查。
- --time-column：默认优先 short_offset_s，用于相对窗口搜索。
- --absolute-time-column：默认使用 matched_time_s，用于输出绝对时间选段。
- --left-column / --right-column：默认 short_value 与 long_value，用于计算 Pearson。
- --min-duration-s：最短窗口 5 秒。
- --duration-step-s：测试窗口长度步长 1 秒。
- --start-step-s：窗口起点滑动步长 0.1 秒。
- --show-duration-sweep：额外打印每个被测试窗口长度的 avg/min/max Pearson，用于确认 5..29 秒都已参与排序。
- --top：输出前 5 个统一窗口长度；每个 rank 的 duration_s 不同。
- --plot-output：rank1 的 char 图 PNG 路径或输出文件夹；默认保存到输入文件夹的 paired_window_rank1_char.png。
- --show-plot：保存后同时弹出 rank1 的 Matplotlib 图窗。
- --no-plot：不生成 rank1 图像。

输出说明：
- 默认输出为对齐表格，每个 CSV 占一行。
- 每行只显示 rank、duration_s、avg_pearson、csv、pearson、p_value、matched_start_s、matched_end_s。
- 同一个 rank 下，所有 CSV 都使用相同 duration_s；不同 rank 的 duration_s 互不相同。
- 运行结束后默认生成 rank1 的 char 图：每个子图只使用对应 paired CSV 的 3000 点中落在该 rank1 窗口内的点；大标题标注窗口大小和点数，小标题附近标注 Pearson、p-value、起始/结束时间。
- 不限制不同 rank 的时间选段是否重叠；区域重叠也会参与排序。


推荐调参顺序
------------
1. 拼接有问题时，先调 vevo_stitcher.py：
   - --seam-check off
   - --max-seam-gap
   - --seam-score-bypass
   - --feature blue/green

2. 曲线提取有问题时，先调 main.py：
   - --roi
   - --target-color
   - --tolerance
   - --min-area

3. 归一化只在比较多份 CSV 时使用 ultrasound_normalizer.py：
   - --duration-s
   - --x-column
   - --y-column

4. 短/长 CSV 区间匹配先调 csv_interval_matcher.py：
   - --short-x-column / --short-y-column
   - --long-x-column / --long-y-column
   - --min-start-separation-s
